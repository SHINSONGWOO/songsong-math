대분수 마을 구출 대작전!

마법의 성에 갇힌 대분수 마을 친구 10명을 구하기 위해 용감한 분수 전사가 모험을 떠납니다!
시작할 때마다 20문제의 숫자가 모두 새롭게 랜덤 출제되니, 몇 번이고 다시 도전해 분수 마스터가 되어보세요!

🌲 1막 (1번 ~ 10번 문제)
아이템 수집의 숲 : 가분수 ➔ 대분수

숲속 문지기들이 내는 가분수를 대분수로 바꾸고, 구출에 꼭 필요한 모험 아이템 10개를 전사의 가방에 채워요!

🚪 2막 (11번 ~ 20번 문제)
대분수 마을 탈출 작전 : 대분수 ➔ 가분수

대분수 모습으로는 좁은 탈출구를 빠져나올 수 없어요! 모은 아이템을 사용해 친구들을 가분수로 변신시켜 탈출시키세요!

🌲 1막: 아이템 수집의 숲 가분수 ➔ 대분수
🔥 연속 정답: 0개
전체 진행: 1 / 20문제
🎒 전사의 아이템 가방 (가분수를 대분수로 바꿔 아이템을 모으세요!) 0 / 10개
🗡️
1번 숲속 문지기 도전 · 획득 보상: 용기의 검

숲속 문지기가 내는 가분수를 대분수로 바꾸면 아이템을 가방에 넣을 수 있어요!

다음 가분수를 대분수로 바르게 바꾼 것은 무엇인가요?

🎉 1막 완료! 전사의 아이템 10개 모두 획득!
🏰🚪✨

드디어 대분수 마을에 도착했어!

😟 큰일 났어! 대분수 마을 친구 10명이 마법의 방에 갇혀 있는데, 마을 탈출구가 너무 좁아서 대분수(자연수+진분수) 모습으로는 빠져나올 수가 없대!

✨ 숲에서 모은 10개의 아이템을 하나씩 사용하면 마을 친구들을 날씬한 가분수로 변신시켜 빛의 탈출구를 무사히 통과하게 할 수 있어!

🔥 2막 임무 (11번 ~ 20번): 대분수 마을 친구들을 모두 가분수로 변신시켜 탈출시키자!
